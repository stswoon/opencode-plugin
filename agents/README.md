# Субагенты

Пакет регистрирует плагином четыре субагента (`mode: subagent`):

| Субагент | Описание | Пишет код | Пишет спеку/план | Когда |
|----------|----------|-----------|------------------|--------|
| **analyst** | Системный аналитик | нет | да (`docs/spec`, `docs/plan`) | `myplan` |
| **dev** | Разработчик | да (`src/` + тесты) | только уточнение цифр | `myimpl`, после замечаний; регрессионный тест на каждый исправимый дефект |
| **qa** | Независимый QA | production-код нет; тесты — если дыра в проверке | нет | после Dev; независимая матрица приёмки в `bug-report-Sxx.md` |
| **lead** | Lead-ревьюер | нет | нет (`review-notes-Sxx.md`) | после доказательного `QA_PASS`, сверка кода и тестов со спекой |

Статус стори (`сделано` / `не сделано`) меняет **оркестратор** `myimpl` после `LEAD_PASS`, не эти агенты.

`myplan` любые допущения и нестыковки выносит вопросами пользователю. `myimpl` допущения закрывает сам (решения `D…` в `.cursor/artifacts/decisions.md`), а нестыковки и расхождения со спекой выносит пользователю.

У subagent нет истории чата: в Task передавай текст стори, решения `D…` этой стори и пути к отчётам предыдущего шага с выжимкой активных блокеров — файлы субагент читает сам, полные тексты не копируй.

Файлы ролей можно также положить в `.opencode/agents/` проекта вручную — формат совместим (frontmatter `name` / `description` / `mode`, тело — системный промпт). В этом случае замени в `analyst.md` плейсхолдер `{{PACKAGE_DIR}}` на путь к пакету.
